## 简介

本书讲透实时语音智能体（Voice Agent）的完整原理：一句话从麦克风进入、到语音从扬声器播出之间，系统内部依次发生了什么，每一段耗时花在哪里，以及为什么它能被随时打断。

全书围绕一条链路展开：

- 总体架构与一轮对话的完整数据流
- 延迟预算：五段耗时的构成、压缩空间与代价
- 断句与打断：本地 VAD 与神经网络 VAD 的取舍
- 语音识别与语音合成的流式处理原理
- 大语言模型在语音场景下的特殊约束
- 检索增强生成与跨通话的长期记忆
- WebRTC、WHIP 协议、DataChannel 与语音流的走向

**本书是原理篇，讲清楚「为什么」。** 完整的 Go 服务端与 Next.js 前端实现、可运行的工程源码，随配套课程提供。

## 技术栈说明

书中讨论的实现基于以下选型，读者可按需替换：

| 环节 | 本书采用 | 可替换为 |
|------|---------|---------|
| 语音识别 | 阿里云 paraformer-realtime-v2 | 腾讯云、火山引擎、Deepgram |
| 语音合成 | 阿里云 cosyvoice-v2 | 腾讯云、火山引擎 |
| 大语言模型 | DeepSeek | 任何兼容 OpenAI API 格式的端点 |
| 传输 | WebRTC + WHIP | |
| 向量检索 | Ollama + ChromaDB | |

中文场景需注意：部分以英文为主的平台，其语音识别支持中文而语音合成不支持，向其提交中文文本不会报错，但输出结果不可用。选型时需分别确认识别与合成两侧。
